**這是一個功能示範站，品牌、商品、價格與規格全部是編出來的。**

建這個站的目的，是展示一套「靜態網站 + 網頁後台」的組合怎麼運作：

- 網站本體是 Hugo 產生的純靜態檔案，沒有資料庫、沒有後端伺服器。
- 內容編輯走 Decap CMS，在瀏覽器打開 `/admin/` 就能改，改完直接 commit 回 GitHub。
- commit 進 main 之後由 GitHub Actions 重新建置並發布，全程不需要開終端機。

也就是說，交付給客戶之後，客戶自己就能改文案、換圖、上架新產品，而你不必為此養一台伺服器。
